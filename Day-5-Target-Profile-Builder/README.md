## ⚙️ Features At A Glance

### 📊 Data Collection

| Feature | Description |
|---------|-------------|
| **GitHub User Profile** | Name, bio, company, location |
| **Public Repositories** | Repository names, descriptions, stars, forks |
| **Programming Languages** | Language detection and frequency analysis |
| **Followers & Following** | Social network mapping |
| **Organization Info** | Company and organization details |

### 🛡️ Risk Assessment

| Feature | Description |
|---------|-------------|
| **Personal Info Exposure** | Full name, location, email, bio |
| **Technical Stack** | Languages and technologies used |
| **Social Network Mapping** | Followers and following analysis |
| **Threat Vectors** | Attack surface identification |
| **Security Recommendations** | Actionable mitigation steps |
| **Attacker Perspective** | Simulated attacker analysis |
